🕹️ What Is This?
A pixel-perfect, from-scratch recreation of the 1980 arcade classic Pac-Man, built using nothing but vanilla JavaScript and HTML5 Canvas. No frameworks. No libraries. Just raw code and nostalgia.

This is being built incrementally — one feature at a time — as a learning exercise in game development.

🗺️ Roadmap
#	Part	Description	Status
1	Game Board & Rendering	Maze, walls, dots, power pellets	✅ Done
2	Pac-Man Movement	Keyboard controls, wall collision	🔲 Next
3	Dot Eating & Score	Eat dots, track score, power pellets	🔲 Planned
4	Ghosts (Basic)	Ghost entities with simple movement	🔲 Planned
5	Ghost AI & States	Chase / scatter / frightened modes	🔲 Planned
6	Game Logic	Lives, levels, win/lose, restart	🔲 Planned
7	Polish	Sound, animations, start screen	🔲 Planned
📂 Project Structure
🚀 How to Run
Clone this repo
Open index.html in your browser
That's it. No build step. No npm install. Just vibes.
